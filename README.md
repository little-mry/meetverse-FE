
# Meetverse - Frontend

Detta är kodbasen för Meetverse-webbplatsen, där användare kan hitta och anmäla sig till meetups och evenemang.

Applikationen är byggd i React (Vite) och TypeScript. Den använder Tailwind CSS för all styling och pratar med ett separat backend-API (som körs på Render).

# Tekniker som används

- Grund: React, React Router

- Byggs med: Vite

- Språk: TypeScript

- Styling: Tailwind

- Pratar med backend: Använder fetch (via en central apiClient-fil)

- Automatisk publicering: GitHub Actions

- Sidan hostas på: AWS S3 (som en statisk webbplats)

# Funktioner

- Logga in och Skapa konto: Användare kan skapa konton och logga in.

- Bläddra meetups: Se alla kommande evenemang.

- Detaljsida: Läs mer om ett specifikt meetup.

- Anmälan: Anmäl dig (och avanmäl dig) från evenemang.

- Profilsida: Se din egen profil med:

  - Din e-post och användarnamn.

  - En lista på "Anmälda" (kommande) och "Tidigare" (passerade) meetups.

- Betygsätt: Lämna betyg och omdöme på evenemang du varit på.
